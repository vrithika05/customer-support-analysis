# 📊 Customer Support Performance Analysis

## 📌 Overview
This project analyzes customer support data to evaluate service quality and customer satisfaction.

## 📊 Features
- Customer Satisfaction (CSAT) analysis
- Channel-wise interaction insights
- Agent shift performance
- Product category issues
- City-wise complaint trends
- Price distribution analysis

## 🛠️ Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn

## 📈 Key Insights
- Most interactions happen via specific channels
- Certain shifts handle more tickets
- Customer satisfaction trends identified
- Top cities generate more complaints

## ▶️ How to Run
pip install -r requirements.txt  
python analysis.py
